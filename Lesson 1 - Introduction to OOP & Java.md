Lesson 1 - Introduction to OOP & Java

OOP is an approach that deal about creating objects containing data and functions. 
Advantages of OOP
- faster and easier to execute
- provides a clear structure for programs
- promotes the DRY (Do not repeat yourself) routine
- used for code reuse; WET (write everything twice)

The OOP structure
CLASSES
- The Blueprint
METHODS
- The Behavior
ATTRIBUTES
- The State / what do they have
OBJECT
- The instance

The Pillars of OOP
ENCAPSULATION
- restricts access to object's internal classes
INHERITANCE
- classes can inherit properties and methods from one another
POLYMORPHISM
- enable objects to take one mutiple forms
- method overriding (a person can have different IDs to log in a site)
ABSTRACTION
- hides unnecessary details

The Java Programming Language
- is a high-level, object oriented programming language
- known for: versatility, effieciency, platform independence
- preferred for: webdev, mobile apps
